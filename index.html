Overview

This project simulates a quantum-inspired green hydrogen production forecasting system using classical ESP32 microcontroller logic. The forecasting function mimics quantum-like superposition by assigning probabilistic weights to possible outcomes: an increase, maintenance, or decrease in hydrogen output. Our goal is to explore how these concepts can be applied to sustainable energy management.

Method

Simulation Architecture:
  • Solar Input (): LDR sensor to simulate light intensity.
  • Water Input (): Potentiometer to simulate electrolyzer water flow or level.
  • Central Processing (): ESP32 module responsible for the quantum-inspired forecasting logic.
  • Forecasting Output (): LEDs visually indicate predicted hydrogen production levels (color and brightness).
  • Data Logging (): Serial Monitor for detailed analysis of inputs, states, and results.

Method & System Architecture

Our final system implements a hybrid simulation architecture. It combines real-world sensor data with digitally generated patterns to create a robust testing environment for the quantum-inspired algorithm. The system is composed of five main functional blocks connected to an ESP32 microcontroller.

System Components & Data Flow:
  • Hybrid Inputs ():
    • Solar Data: A weighted mix of real-world data from an LDR sensor and a digitally generated sine wave pattern.
    • Water Data: Purely digitally generated sine wave patterns to simulate varying electrolyzer water levels.
  • Central Processing Unit (): The ESP32 runs the quantum-inspired probabilistic forecasting algorithm, including a memory weight feature for output stabilization.
  • Dual-OLED Visualization (HMI) ():
    • OLED 1 (Status Monitor): Displays real-time input percentages and bar graphs for Solar, Water, and H2 Potential, along with the final forecast text.
    • OLED 2 (Trend Analysis): Draws a live, scrolling line graph showing the history of the predicted H2 production potential.
  • Forecast Indicator (): An RGB LED provides immediate visual feedback of the forecast (Green=Increase, Blue=Stable, Red=Decrease).
  • Data Logging (): Outputs CSV-formatted data via the Serial port for external analysis.

Key Algorithm Features

  • Quantum-Inspired Probabilistic Forecasting: Instead of deterministic outputs, the system calculates probabilities for three superpositioned states (Increase, Stable, Decrease) and collapses them to a single decision, mimicking quantum measurement uncertainty.
  • Memory Weight Stabilization: To prevent erratic switching between forecasts when probabilities are close, a "memory" factor adds weight to the previous decision in the next calculation. This introduces realistic system inertia and stability.
  • Hybrid Data Fusion: The system intelligently combines real-time sensor readings with generated data patterns, allowing for robust testing across a wide range of simulated environmental scenarios.

My primary focus was on developing the quantum-inspired theoretical framework and algorithmic foundation that powers the hydrogen production forecasting system.

Key contributions included:

  • Adaptive Decision-Making: Introduced and tuned quantum noise injection to enable adaptive, non-deterministic decision-making that responds dynamically to environmental changes.
  • Theoretical Framework: Defined the quantum-inspired decision logic independent of machine learning or data training, providing a pure probabilistic approach to uncertainty modeling.
  • System Behavior Guidance: Provided the theoretical quantum-inspired framework that guided overall system behavior and forecasting logic throughout the project.
